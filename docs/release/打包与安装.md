# 打包与安装

## Windows 打包（CMD）

```bat
pnpm install --frozen-lockfile
pnpm build
dir dist\artifacts
```

安装：运行 `Biu-<版本>-win-setup-x64.exe`；ARM 机器选择 `arm64`。便携版运行 `win-portable` 文件。

## Mac 打包（终端）

```bash
pnpm install --frozen-lockfile
pnpm build
ls dist/artifacts
```

安装：打开 `Biu-<版本>-mac-arm64.dmg`，将 Biu 拖进 Applications；Intel Mac 选择 `x64`。

## 上传发布

按 [Windows / Mac 发布命令](README.md)操作。`pnpm build` 只构建安装包，上传是下一步。
