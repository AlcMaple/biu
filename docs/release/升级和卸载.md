# 升级和卸载

## Windows NSIS 安装版

### 自动升级

已接入签名更新通道的安装版，在设置中点击「检查更新」，按提示下载并安装。首次接入或旧更新地址迁移的处理，见[发布指南的旧版兼容说明](README.md#4-把客户端更新地址改成自己的首次执行)。

### 手动覆盖升级

1. 从可信发布来源取得与机器架构对应的 `Biu-<版本>-win-setup-x64.exe` 或 `arm64.exe`。
2. 退出 Biu，包括托盘中的进程。
3. 运行新版安装包，在原安装目录完成安装，再启动确认版本。

覆盖安装可保留本机状态；卸载重装也不会删除云端已经同步的数据。

### 卸载

在 Windows「设置 → 应用」中卸载。当前 `deleteAppDataOnUninstall: true` 会清理本机用户数据目录，不会调用云端删除接口。

- **能恢复**：在 Biu 中本地创建的歌单、歌单里的歌曲条目、重命名后的歌名、新建标签及歌曲标签关系，前提是已成功同步。重装后登录同一 B 站账号、连接同一同步服务，等待同步完成即可。这里的账号用于识别同步用户，这些数据不是 B 站收藏夹。
- **不能靠云同步恢复**：尚未上传的改动、登录状态、本机设置、精美播放器本地图片，以及本地音乐文件本身。卸载对文件的影响取决于文件是否放在被清理的目录里。
- 首次同步会先拉取云端数据并合并，不会因为重装后的本地数据为空就把云端内容删空。

卸载重装前确认同步成功；仅保存在本机的内容需要另外备份。

## Windows 便携版

便携版不支持自动安装更新。退出正在运行的程序，保留数据备份后使用新的 portable EXE；删除旧 EXE 只删除程序文件，不应顺手删除用户数据目录。

## macOS

退出 Biu，打开新版 DMG，把 `Biu.app` 拖到 Applications，在系统询问时选择替换。当前免费安全自动更新方案仅覆盖 Windows NSIS，macOS 使用手动升级。

首次安装可能受到系统开发者验证提示；先确认下载来源。macOS 构建和安装说明见[打包与安装](打包与安装.md)。卸载应用可将 `Biu.app` 移到废纸篓；用户数据的清理与删除应用是两件事。
