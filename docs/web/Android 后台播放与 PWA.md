# Android 网页版后台播放与 PWA

## 现象

部分 Android 手机（尤其是游戏手机）会在用户切到后台后自动清理浏览器进程，音乐随之停止。该行为由厂商的内存管理策略决定，与系统省电模式无关。**网页代码无法阻止进程被杀**，只能降低被杀概率、并在被杀后无缝接回。

## 代码侧的对策

| 对策 | 位置 | 说明 |
| --- | --- | --- |
| Android 浏览器默认不建 Web Audio 图 | `src/common/utils/audio-graph.ts` | `createMediaElementSource` 建好后不可撤销，音频从此走 AudioContext：后台里容易被挂起（静音），也更像「非媒体播放」。Android 浏览器上波形 / 星云等纯装饰可视化不再触发建图（退回装饰动画）；只有用户主动开了「音量增强」才建图 |
| 播放进度定期落盘 | `src/store/play-progress.ts` | 播放中每 3 秒写一次 `localStorage`。进程被杀时 `beforeunload` 不会触发，只靠它会丢进度；现在重开后停在上次位置，点播放即可继续（浏览器不允许刷新后自动出声） |
| 后台中断诊断 | `src/platform/web-lifecycle-diagnostics.ts` | 把生命周期事件轨迹写入 `localStorage`；下次冷启动发现上次在后台中断，向服务端日志补报一条 warn（含后台停留时长、事件轨迹）。后台中音频被暂停时实时上报 info。只记录，不改变播放行为 |
| PWA 可安装 | `public/manifest.webmanifest`、`public/pwa/*`、`src/index.html` | 安装后以独立应用运行（独立图标、媒体通知），厂商后台管理对它更宽容，也便于用户单独加白名单。**暂不注册 service worker**，避免与「HTML `no-store`、靠哈希资源更新」的发版方式冲突 |
| 用户指引 | 设置 →「后台播放」（仅手机网页布局可见）`src/pages/settings/background-play-guide.tsx` | 安装按钮 + 分品牌的「不要清理」步骤 |

### 在日志里怎么看

回传日志（`BIU_WEB_CLIENT_LOG_DIR`）里搜：

- `上次会话在后台中断`：上次在后台中断。`hiddenForMs` 是进入后台到最后一次心跳的时长，`wasPlaying` 是当时是否在播放，`trail` 是最后一批事件（带 `*` 表示当时在播放）。`wasPlaying=true` 且 `hiddenForMs` 较短，基本就是被系统清掉。
- `后台中音频被暂停`：页面在后台时音频被暂停。可能是用户点了通知栏，也可能是系统强制暂停，结合 `trail` 判断。

## 给用户的话术（不用改代码）

切到后台就停，是手机系统在清理后台。需要在手机里给 Biu（或浏览器）放行一次：

1. **安装到主屏幕**：用 Chrome 打开网页，菜单「⋮」→「安装应用 / 添加到主屏幕」。
2. **锁定最近任务卡片**：最近任务里下拉卡片（或长按）选择「锁定」，防止一键清理。
3. **放开电池 / 后台限制**：应用管理里把 Biu（或浏览器）的省电策略设为「无限制 / 不优化」，允许「自启动」和「后台运行」。
4. **游戏手机**：在「游戏空间 / 性能模式 / 内存管理」里把它加入白名单。

各品牌入口名称不同，网页「设置 → 后台播放」里有分品牌的步骤，找不到时可在系统设置里搜索「电池优化」「自启动」「后台运行」「应用锁定」。

被清理后重新打开，会停在上次的位置，点一下播放即可继续。

## 验证清单

- Chrome（Android）打开站点，菜单里出现「安装应用」；安装后图标为绿色 Biu 电视图标，圆形遮罩下不被裁切（maskable 图标）。
- 设置 →「后台播放」页点「安装到主屏幕」能弹出系统确认。
- 播放中杀掉浏览器再打开：停在上次位置；服务端日志出现「上次会话在后台中断」。
- 在 Android 浏览器里打开全屏播放器 / 私人FM：不再建立 Web Audio 图（音量增强保持默认 100% 时）。
