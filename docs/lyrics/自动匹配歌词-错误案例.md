# 自动匹配歌词：错误案例库

目的：用户每次提供「自动提取歌名/匹配歌词出错」的真实案例，在这里登记，并基于案例修复
`src/components/lyrics/auto-match.ts`。随案例积累，尽量覆盖更多标题写法；个别案例之间难免冲突，以整体收益最大为准。

## 约定
- 每次修复后，**回归检查全部旧案例**（用 `extractTitleCandidates` 跑一遍，期望的歌名必须出现在候选前列）。
- 改动提取/打分逻辑后，把 `AUTO_MATCH_VERSION` +1：旧的「自动」缓存会重新匹配，**手动采用的歌词（`source: manual`）永不被覆盖**。
- 冲突取舍写在案例的「备注」里。
