## Decisions and Constraints

- **Confirmed**：三类外观都要；Lumisynth 不是仅作镜台编排参考，也不是镜台别名。既有声学逐字对齐保留；平台原唱时间轴与当前翻唱/现场/剪辑录音分别处理。
- **Confirmed**：Biu 保持 PolyForm Noncommercial。Folia/Lumisynth 渲染代码、`@applemusic-like-lyrics/ttml@1.0.1` 为 AGPL，按文档边界独立设计实现；可选底层库仍需锁版本、保留许可并检查依赖。研究过源码不等于可逐行改写后宣称 clean-room。AMLL 数据许可与解析器、歌词内容权利分开。
- 先读 `AGENTS.md`：保留现有构建、严格 TS、UI、framer-motion、Zustand 和跨窗通道。需要 Cookie/UA 的请求走主进程/固定平台能力；Web 走受限 BFF，原生移动端按实际能力接入。避免任意 URL 代理、renderer 裸发和用空实现冒充已支持。
- 复用 `readPlaybackMs()` 和毫秒时间轴，当前歌词显示按 `ms + offset`；偏移只应用一次。保留原生词结束时间。`MusicLyrics.source` 已表示 manual/auto/aligned/approved，另设来源元数据，保护用户采用、还原和禁止自动对齐的意图。
- 酷狗已验证路径：曲库 Hash/时长 → 歌词候选 → 下载/解码 KRC，注意秒/毫秒。QQ 非零业务码 `2001` 保留为检索异常，勿伪装未收录；QQ 原生 QRC 未测，可先利用已验证 LRC 与现有对齐能力。429/5xx 不自动重试、不探测恢复、不静默吞错，检查 SDK 内部重试。
- 新测试放 `tests/`。响应式保持同一组件树；完整交互样例先覆盖控制、设置与异常状态，再接主界面。保留桌面歌词窗口的全屏游戏保护规则。提交、推送、部署须另获用户明确要求。
