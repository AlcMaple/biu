# Biu 响应式离线 Demo

这里不是另做一套静态页面，而是项目真实 React 路由树的离线构建：`Layout`、Navbar、侧栏、播放栏、列表、弹窗、抽屉和响应式断点全部直接复用 `src/`。唯一替换的是服务层：使用本地 fixture，不登录、不读取真实 Cookie、不请求 Bilibili、BFF、同步服务或媒体 CDN。

实现原理、Biu 生产落地、SSL 配置、可照抄/需适配/必须重新生成的边界，以及跨服务器/项目迁移规则见 [响应式离线 Demo：实现、落地与迁移规范](./网页原型设计.md)。

## 运行

在仓库根目录执行：

```bash
pnpm build:responsive-demo
```

然后打开 [full-demo.html](./full-demo.html)，或直接打开生成的 [runtime/index.html](./runtime/index.html)。如果浏览器限制 `file://` 的相对资源，可以在本目录启动任意静态服务器；例如：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

## 页面与状态

- 推荐、搜索、私人 FM、历史记录、稍后再看、下载记录、本地音乐。
- 收藏夹、视频合集、视频系列、我的关注、用户动态、用户空间、设置、空状态和 404。
- 手机侧栏、播放列表抽屉、收藏选择、确认、下载选择、全屏播放器和播放器设置。
- 播放/暂停、上一首/下一首、全部播放、菜单操作、收藏、下一首播放、加入播放列表和提示反馈。

截图所示的本地 `all` 收藏夹入口是 `#/local-collection/-3`；远程收藏夹 `#/collection/101` 是另一种页面状态，排序和批量下载菜单不能混用。

## 响应式检查尺寸

`320×568`、`375×667`、`667×375`、`768×900`、`1000×900`、`1440×900`。

断点与共享 React 组件一致：`≤767px` 移动、`768–820px` 窄平板、`821–1050px` 平板、`≥1051px` 桌面。Demo 只用于视觉和交互回归；响应式改动直接修改 `src/`，不要再维护第二套页面 JSX。
