# 全量响应式离线 Demo

这是项目真实 React 路由树的离线构建，不是手写静态截图：Layout、Navbar、侧栏、播放栏、页面列表、弹窗和抽屉都直接来自 `src/`。页面只把服务层请求替换为本地 fixture，不登录、不读取真实 Cookie、不访问 Bilibili、BFF、同步服务或媒体 CDN。

完整的架构说明、Biu 生产落地、SSL 配置、状态边界和迁移规则见 [响应式离线 Demo：实现、落地与迁移规范](./网页原型设计.md)。

截图所示的本地收藏夹使用 `#/local-collection/-3`（fixture 中标题为 `all`）；`/collection/101` 是远程收藏夹页面，保留其独立的远程排序和批量下载菜单，不要把两个页面的控件混用。

在仓库根目录运行 `pnpm build:responsive-demo`，然后直接打开同目录的 [`full-demo.html`](./full-demo.html)，或打开生成的 [`runtime/index.html`](./runtime/index.html)。不需要启动 Biu；若浏览器对 `file://` 的相对资源有限制，再用 `python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/responsive-prototype` 预览。

## 可巡检页面

- 推荐音乐、搜索结果、私人 FM
- 收藏夹详情：B 站收藏夹、视频合集、视频系列、本地收藏
- 历史记录、稍后再看、下载记录、本地音乐
- 我的关注、用户动态、用户空间、设置
- 空状态、404 状态
- 手机侧栏、播放列表抽屉、收藏选择弹窗、确认弹窗、下载选择弹窗、全屏播放器

## 交互覆盖

- 分类、排序、搜索建议、搜索/日期筛选、列表与卡片展示模式（沿用真实组件）
- 播放 / 暂停 / 上一首 / 下一首 / 全部播放 / 播放列表
- 歌曲行更多菜单：收藏、下一首播放、加入播放列表、下载
- 本地收藏夹移动端：第一行保留“播放全部 / 更多”，第二行完整显示标签和搜索；手机隐藏“添加到播放列表”，把“失效内容”放进“更多”，不产生横向滚动
- 弹窗打开、勾选、确认、取消，以及动态提示位置

## 推荐检查尺寸

`320×568`、`375×667`、`667×375`、`768×900`、`1000×900`、`1440×900`。

断点与 React 共用：`≤767px` 移动、`768–820px` 窄平板、`821–1050px` 平板、`≥1051px` 桌面。手机和横屏状态栏播放进度独立占位，底部播放栏不会覆盖内容。

Demo 与 `src/` 共用同一棵路由/组件树；响应式修改直接改 `src/`，Demo 只用于在无真实接口的条件下做视觉回归。
