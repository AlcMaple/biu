# 私人 FM 页面重设计：市场调研与方案

## 现状问题（线上截图）

黑胶 + 三层绿色同心圆涟漪 + 粒子星云 + 封面模糊漂移背景 + 逐字模糊浮现并扫光的歌名 + 长按蓄力彩蛋 + 「特效已简化」开关。
信息少（只有歌名、UP 主、一个心形），动效占据视觉重心，且同时有 4 种常驻动画（旋转、涟漪、漂移、粒子）。用户反馈「丑」，粒子不被接受。

## 调研对象与结论

资料来源：网易云「心动模式 / 私人漫游 / 2024 播放页改版」报道（[人人都是产品经理](https://www.woshipm.com/evaluating/4213966.html)、[优设](https://www.uisdc.com/netease-music-heartbeat-mode)、[中国音乐网](http://www.chnmusic.cn/zhxw/2024/0109/11381.html)）、Spotify / Apple Music / YouTube Music 的横向体验评测（[Medium](https://medium.com/design-bootcamp/a-sonic-deep-dive-spotify-vs-apple-music-vs-youtube-music-41dea45d2106)、[SnappyMob 审计](https://blog.snappymob.com/ui-ux-audit-spotify-vs-apple-music)）。
说明：这些来源以文字评测为主，没有逐像素的官方文档；下表布局结论是对这些产品公开界面的归纳，实现前建议用户对照自己手机上的 App 再确认一次。

| 产品 | 页面形态 | 视觉重心 | 动效 | 操作 |
|---|---|---|---|---|
| 网易云 心动模式 / 私人漫游 | 就是普通播放页，只是播放模式之一；漫游为一级 Tab，上下滑切歌 | 大封面（黑胶仅作为播放页皮肤，可关） | 仅唱片旋转；2024 改版明确「更简洁、去掉与听歌无关的功能」 | 红心、评论、下一首放在拇指区，强化红心 |
| QQ 音乐 猜你喜欢 / 电台 | 同样复用播放页，顶部标明来源 | 封面 + 歌名 | 克制 | 喜欢、不喜欢、下一首 |
| Spotify Radio / 智能电台 | 以「来源标题」+ 队列呈现，无独立特效页 | 封面取色铺底渐变 | 几乎无 | 喜欢、不喜欢/隐藏、下一首 |
| Apple Music 电台 | 大封面居中，白/取色底 | 封面本身 | 切歌时封面缩放过渡 | 极简 |
| YouTube Music 电台 | 上方「来源：XX 电台」，封面 + 操作行 | 封面 | 无 | 点赞/点踩、下一首 |

## 业界共识

1. 个性化连续播放没有「特效页」，就是播放页：封面是唯一视觉主角。
2. 背景最多是「封面取色/模糊铺底」，静态或极慢变化，不做粒子、波纹。
3. 标明来源/模式（「私人FM」「基于你喜欢的音乐」），让用户知道这一列歌为什么出现。
4. 操作行固定在拇指区：喜欢（最大）、不喜欢/跳过、下一首；一眼能找到，不靠长按/悬停。
5. 动效只在状态变化时出现一次（换歌过渡、点赞反馈），平时静止。

## 重设计方案

**去掉**：粒子星云、同心圆涟漪、背景漂移动画、歌名逐字模糊 + 扫光、长按蓄力彩蛋、「特效已简化 / 完整特效」开关。
理由：是对 1–5 的直接背离；长按彩蛋在 Web 触屏上不可发现且与点按冲突；开关只为粒子的性能服务，粒子删除后无存在意义。已确认 `useHeartbeatFx`、`NebulaCanvas` 仅被本页引用，可连同 `src/store/heartbeat-fx.ts`、`nebula-canvas.tsx` 一并删除。持久化 key `heartbeat-fx` 遗留在本地存储无副作用。

**保留 / 新做**（同一棵组件树，仅 className 响应式）：

- 背景：封面模糊铺底 + 渐变压暗，静态（换歌时 framer-motion 交叉淡入 300ms）。
- 顶部小标签「私人FM」（来源标识，非说明文案）。
- 封面：方形圆角大图（桌面 ~320px，平板 ~280px，手机取宽度 72% 上限 320px）；暂停时不旋转不变形，仅轻微缩放（盒模型不变，用 transform，播放 1 / 暂停 0.94）。取消黑胶。
- 歌名（最多 2 行）+ UP 主，左对齐于封面下方或居中：桌面 / 平板居中，与现页一致。
- 操作行：喜欢（主按钮，实心红心状态）、下一首、可选「跳过不喜欢」暂不做（推荐逻辑不动，不新增能力）。喜欢按钮常显文字态通过图标颜色与 aria-label 表达，不加说明文案。
- 换歌：封面 + 歌名 framer-motion 淡入上移一次。
- 减少动效偏好：`prefers-reduced-motion` 下取消过渡。
