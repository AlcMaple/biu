## 更新内容

### 歌词

- 新增自动校准歌词
- 自动匹配新增 QQ 音乐、酷狗和 AMLL 三个歌词来源
- 自动识别B站的填词、改词音频
- 在「歌词设置」里新增开关译文和罗马音
- 新增「歌词报错」提交更正，侧边栏「我的提交」查看处理结果

### 歌单与分享

- 本地歌单和标签改跟随 B 站账号，老用户通过「设置 → 常规设置」认领旧歌单
- 新增分享单曲、公开 B 站收藏夹和本地歌单
- 本地歌单新增为失效视频查找同名、时长相近的版本并自动替换，在「失效记录」里可以撤销替换，也可以自己搜索
- 歌单新增「定位当前播放」

### 播放与听歌记录

- 播放栏新增「定时关闭」
- 听歌排行支持跨设备自动同步
- 「私人 FM」更名为「相似推荐」
- 新增「问题反馈与建议」

### 修复与优化

- 修复本地歌单同步时，刚收藏的歌曲或刚改的标签被覆盖、刚删的歌曲又出现
- 修复桌面歌词切歌后偶尔空白、开着桌面歌词退出时报错
- 优化切歌播放速度
- 播放和下载优先选择更稳定的线路，减少使用代理时卡住的情况
- 遇到 B 站限流时，播放器会暂停当前歌曲，提示稍后再播
- 从播放列表或本地歌单下载多 P 视频中的一集时，只下载选中的分 P
- 下载记录按时间从新到旧排列
